# 📊 Financial Loan Analysis Dashboard | Excel

An interactive **Financial Loan Analysis Dashboard** built using Microsoft Excel to analyze loan applications, funded amounts, received amounts, interest rates, DTI, and loan performance.

## 📌 Project Overview

This project analyzes financial loan data to understand:

- Loan application performance
- Funded and received loan amounts
- Good vs Bad loan performance
- Loan status
- Interest rate
- Debt-to-Income (DTI)
- Loan grade and purpose

The dashboard provides an interactive way to explore important loan-related KPIs and trends.
